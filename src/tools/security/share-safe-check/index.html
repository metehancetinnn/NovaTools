      Files carry more than what you see on screen

      A photo can carry the exact place it was taken and the serial number of the phone. A Word file keeps the names of everyone who edited it and, with tracked changes on, the text they deleted. A PDF that was edited and saved again often still holds the earlier version inside it. A browser HAR recording that a support team asks for contains the session cookies that keep you signed in.

      None of this shows up when you open the file normally, so it is easy to send without noticing. These are not rare cases:

      • In a study of 39,664 PDFs published by 75 government security agencies, researchers recovered details such as author names, operating systems and file paths from most of them; only three agencies had removed everything.
      • In 2023, attackers used session tokens from HAR files that customers had uploaded to Okta's support system; Okta's root-cause report describes the incident.
      • PDF experts have documented how black boxes drawn over text in government releases left the text readable underneath — see the PDF Association's case study.

      How to use it

      1. Choose the file you are about to share. The report lists what was found, highest risk first.
      2. Select Create cleaned copy. The tool removes what it can and then runs the same checks on the new copy.
      3. Read the re-check result. Anything marked “fix it in the app that made the file” needs one more step there — for example accepting tracked changes in Word or deleting a hidden sheet in Excel.
      4. Download the cleaned copy, open it once to make sure it looks right, and send that file.

      Known limitations

      • The checks look for known places where data hides. A clean result means none of those were found, not that the file is guaranteed safe. The visible content — what the page, photo or sheet actually shows — is yours to review.
      • Text hidden under black boxes is found but not removed: removing it means rebuilding the page. Use PDF Redact & PII Check, which rebuilds each page as an image, then check its output here. The check compares each word's position with the rendered page, so text in unusual layouts (rotated, very tight columns) can be missed, and some hits are harmless, such as the invisible search layer a scanner adds over a scanned image or white template labels. Only the first 60 pages are rendered; the report says when pages were skipped.
      • Encrypted or password-protected files cannot be inspected fully. Remove the password first.
      • HEIC photos from iPhones cannot be read in the browser yet. Export them as JPEG, or turn off location when sharing from the Photos app.
      • Office files: only the person, company and timeline properties are cleaned. Saved preview images and custom properties are reported but left in place, and photos inside the document keep their metadata until you re-insert cleaned copies.
      • Older .doc, .xls and .ppt files are not supported; save them in the newer format first.
      • Files up to 50 MB, one at a time.

      Privacy

      The file is read into this browser tab and processed there with code served from mc-novatools.com. It is not uploaded, logged or stored by NovaTools, and closing the tab discards it. The only optional outside link is “See this point on OpenStreetMap”, which appears when a photo has a GPS location and sends just those coordinates if you choose to open it. If you accept analytics cookies, the page also records that a check or cleaning ran, the file type, a size range, how many items were found and whether the re-check passed, so we can see whether the tool is useful. It never records the file name, its contents or what was found in it.

      Frequently asked questions

      Does removing metadata reduce photo quality?

      No. For JPEG, PNG and WebP the metadata blocks are cut out of the file and the compressed image data is copied unchanged.

      Why are tracked changes and hidden sheets not removed automatically?

      Because they are content. Accepting or rejecting a change, or deleting a sheet, changes what the document says, and that decision should be made in Word or Excel where you can see the result.

      Is the cleaned PDF still searchable?

      Yes. Pages, text and links are kept; only metadata, attachments, scripts and (if ticked) review marks are removed.

      Can I use it for files other people send me?

      Yes — it is a quick way to see who made a document, when, and whether it carries earlier versions or hidden sheets.
